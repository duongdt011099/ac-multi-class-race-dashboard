---

name: release-changes
description: Summarizes the changes made in the current main branch code compared to the latest release tags.

---

Pre-Usage:
  - Make sure you fetch the latest tags from the remote repository before running this skill.

Usage:
  - Summarize the changes made in the current main branch code compared to the latest release tags.
  - Provide a summary of the changes made in the current main branch code compared to the latest release tags, including any new features, bug fixes, or other notable updates.
  - Summarize as bullet points the changes made in the current main branch code compared to the latest release tags, highlighting any new features, bug fixes, or other notable updates.

Format:
  - Summarize the changes as short bullet points for user-friendly readability.
  - Don't dive into the code details; focus on the high-level changes and their impact.
  - Print out as github release notes format, including the version number and release date.
